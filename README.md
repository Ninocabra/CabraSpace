# CabraSpace — PixInsight update repository

This folder is a PixInsight update repository (`updates.xri` + one package per script).

To install: in PixInsight, **Resources > Updates > Manage Repositories**, add this repository's address, then
**Resources > Updates > Check for Updates** and select the packages you want. They appear under **Script > CabraSpace**.

Packages (release 20261106):

- **FieldDepth3D** 1.0.4 — `20261106-FieldDepth3D-1.0.4.zip` (sha1 `d03a0f73f757d6f6bde8e2b5d461931cc3de12d7`)
- **StellarChemistry** 0.3.3 — `20261106-StellarChemistry-0.3.3.zip` (sha1 `397b7c9086cd465fe18f57a5cb94e2faafa84000`)

Network use, external programs, files written and third-party data are documented in each script's help
(button ?) and in the `THIRD_PARTY.txt` installed with each script.
